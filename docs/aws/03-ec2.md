# Amazon EC2 — Manual MVP Host (Planned)

**Status: not implemented or deployed.** The current Terraform root targets ECS/Fargate and has no EC2 resource. This guide records a safe manual-learning path, not a claim that an instance exists.

Before creating an instance, compare its memory and expected concurrent services with the Docker Compose stack, review current Mumbai-region pricing, and set an AWS Budget. Prefer a small Graviton instance only after confirming image compatibility and RAM; no instance type is promised to fit without measurement. Use an encrypted EBS volume, a dedicated instance profile, and Systems Manager Session Manager. Do not expose SSH to the internet or use root credentials.

Inspect EC2 → Instances, Security Groups, and Volumes. CLI inspection: `aws ec2 describe-instances --filters Name=tag:Project,Values=jobpilot`. Terraform/manual commands for creating an instance are intentionally omitted until instance size, cost, access, and user approval are reviewed. Use CloudWatch status checks and SSM inventory to troubleshoot. Stop an idle instance to reduce compute charges, while noting EBS and snapshots continue to cost. Terminate only after backing up persistent data and checking attached volumes.
